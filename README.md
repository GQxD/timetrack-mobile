# TimeTrack Pro – mobile

Badgeuse et suivi des heures / repos compensateurs, installable sur iPhone (web app, sans App Store).

- App : https://gqxd.github.io/timetrack-mobile/
- Installation : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
- Les heures restent stockées sur le téléphone. Échange avec l'app PC par export / import de fichier (onglet Données).
